# UpSkillr — Fullstack MERN Education Platform

UpSkillr is a modern, full-stack educational web application built with the **MERN** stack (MongoDB, Express, React, Node.js). It provides an intuitive, high-performance platform for learners to acquire in-demand skills and for instructors to create, manage, and monetize expert courses.

---

## 🌟 Key Features

- **Modern Landing Page**: Polished educational design with responsive layouts and rich micro-interactions.
- **Theme Customization**: Full **Light Mode** and **Dark Mode** support with smooth color transitions and persistent state.
- **Modular Component Architecture**: Clean separation of reusable UI components (`common/`, `home/`, `pages/`).
- **Accessible & Responsive**: Optimized for desktop, tablet, and mobile breakpoints with WCAG AA compliance.

## 🚀 Quick Start Guide

### Frontend Setup
```bash
# Navigate to Frontend folder
cd Frontend

# Install packages
npm install

# Start Vite development server
npm run dev
```

### Backend Setup
```bash
# Navigate to Backend folder
cd Backend

# Install packages
npm install

# Start Node server
npm start
```
